Privacy Policy

Last updated: 15 September 2026

Neo Quiz has no account, no telemetry, no analytics and no ads. It runs on your device and keeps your data there. Its author, Ahmed Mili, operates no server and receives nothing from the app. The only network connections are listed below, one by one.

1. What is stored, and where

Everything Neo Quiz stores stays on your computer, in plain files you can open, copy or delete:

  • Your quizzes: Markdown notes in the folders you open in the app (or in your Obsidian vault, for the plugin).
  • Your review history: which questions you answered and when, in a .neo-quiz/review-log.jsonl file inside each of those folders. It only ever grows by appending lines and can be deleted to start over.
  • App settings: language, opened folders, AI tool preferences, window state, in settings.json under your user profile (%APPDATA%\Neo Quiz on Windows).

Uninstalling removes the program and leaves these files in place, so nothing of yours is lost by mistake. Delete them yourself if you want them gone.

2. Network connections

The app and its installer connect to exactly these services, and to nothing else:

  • GitHub (github.com): the installer downloads the application package from the project’s releases; the desktop app checks there for a newer version when it starts and periodically while it runs (you can turn this off in Settings). GitHub sees your IP address and standard request metadata, under the GitHub Privacy Statement.
  • Ollama (ollama.com, and the Ollama server you configure, local by default): the list of available models, when you open the AI generation page. See Ollama’s privacy policy.

3. AI generation

Generating a quiz is optional and only happens when you start it. The prompt you write and the notes or PDF text you attach are handed to the tool you selected, which sends them to its provider under your own account:

  • Claude Code CLI → Anthropic (privacy policy);
  • Codex CLI → OpenAI (privacy policy);
  • Ollama → your own machine, or Ollama’s cloud if you chose a cloud model.

The tools are launched without any file access: the model cannot read anything on your disk by itself. Only what you explicitly attach is sent, and Neo Quiz never sees or keeps a copy of the exchange beyond the quiz it writes into your note.

4. This website

The download pages are static files hosted on GitHub Pages, which logs requests under the GitHub Privacy Statement above. They set no cookies and run no analytics. The only thing kept in your browser is your language choice, in localStorage, once you pick one from the menu.

5. Sharing, children, your rights

No personal data is collected, so none is shared, sold or transferred, and there is nothing to request access to or deletion of: your data is the files above, under your control. Neo Quiz is not directed at children and collects nothing from anyone.

6. Changes

If a future version connects to a new service or stores something new, this page will say so, with a new date above.

7. Contact

Questions go through the project’s GitHub issues.
