Politique de confidentialité

Dernière mise à jour : 15 septembre 2026

Neo Quiz n’a ni compte, ni télémétrie, ni analytique, ni publicité. Il tourne sur votre appareil et y garde vos données. Son auteur, Ahmed Mili, n’exploite aucun serveur et ne reçoit rien de l’application. Les seules connexions réseau sont listées ci-dessous, une par une.

1. Ce qui est enregistré, et où

Tout ce que Neo Quiz enregistre reste sur votre ordinateur, dans des fichiers lisibles que vous pouvez ouvrir, copier ou supprimer :

  • Vos quiz : des notes Markdown dans les dossiers que vous ouvrez dans l’application (ou dans votre coffre Obsidian, pour le plugin).
  • Votre historique de révision : quelles questions vous avez répondues et quand, dans un fichier .neo-quiz/review-log.jsonl à l’intérieur de chacun de ces dossiers. Il ne fait que grandir par ajout de lignes et peut être supprimé pour repartir de zéro.
  • Les réglages de l’application : langue, dossiers ouverts, préférences des outils d’IA, état de la fenêtre, dans settings.json sous votre profil utilisateur (%APPDATA%\Neo Quiz sous Windows).

La désinstallation retire le programme et laisse ces fichiers en place, pour que rien de vôtre ne disparaisse par erreur. Supprimez-les vous-même si vous n’en voulez plus.

2. Connexions réseau

L’application et son installateur se connectent exactement à ces services, et à rien d’autre :

  • GitHub (github.com) : l’installateur télécharge le paquet de l’application depuis les releases du projet ; l’application de bureau y vérifie l’existence d’une version plus récente à son démarrage, puis périodiquement (désactivable dans les Réglages). GitHub voit votre adresse IP et les métadonnées habituelles d’une requête, selon la déclaration de confidentialité de GitHub.
  • Ollama (ollama.com, et le serveur Ollama que vous configurez, local par défaut) : la liste des modèles disponibles, quand vous ouvrez la page de génération par IA. Voir la politique de confidentialité d’Ollama.

3. Génération par IA

Générer un quiz est facultatif et n’a lieu que quand vous le lancez. Le prompt que vous écrivez et les notes ou le texte de PDF que vous joignez sont remis à l’outil que vous avez choisi, qui les envoie à son fournisseur sous votre propre compte :

  • Claude Code CLI → Anthropic (politique de confidentialité) ;
  • Codex CLI → OpenAI (politique de confidentialité) ;
  • Ollama → votre propre machine, ou le cloud d’Ollama si vous avez choisi un modèle cloud.

Les outils sont lancés sans aucun accès aux fichiers : le modèle ne peut rien lire sur votre disque de lui-même. Seul ce que vous joignez explicitement est envoyé, et Neo Quiz ne voit ni ne conserve l’échange au-delà du quiz qu’il écrit dans votre note.

4. Ce site

Les pages de téléchargement sont des fichiers statiques hébergés sur GitHub Pages, qui journalise les requêtes selon la déclaration de confidentialité de GitHub ci-dessus. Elles ne posent aucun cookie et n’ont aucune analytique. La seule chose gardée dans votre navigateur est votre choix de langue, dans localStorage, une fois que vous en avez choisi une dans le menu.

5. Partage, mineurs, vos droits

Aucune donnée personnelle n’est collectée, donc rien n’est partagé, vendu ni transféré, et il n’y a rien dont demander l’accès ou la suppression : vos données sont les fichiers ci-dessus, sous votre contrôle. Neo Quiz ne s’adresse pas aux enfants et ne collecte rien de personne.

6. Modifications

Si une version future se connecte à un nouveau service ou enregistre quelque chose de nouveau, cette page le dira, avec une nouvelle date ci-dessus.

7. Contact
