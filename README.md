### `Neo Quiz`

[![Release](https://img.shields.io/github/v/release/Neo-Quiz/neo-quiz?label=release&display_name=tag)](https://github.com/Neo-Quiz/neo-quiz/releases)
[![Build](https://img.shields.io/github/actions/workflow/status/Neo-Quiz/neo-quiz/release.yml?label=build&logo=github)](https://github.com/Neo-Quiz/neo-quiz/actions/workflows/release.yml)

Neo Quiz turns your notes into interactive quizzes, generated by the AI tools you already have. Windows and Linux.

[Download](https://neo-quiz.github.io/) • [Release Notes](https://github.com/Neo-Quiz/neo-quiz/releases) • [Code signing policy](docs/guide/install.md#code-signing-policy)

## What you get

- `App` - Read, review, edit and generate quizzes from any folder of Markdown notes. Updates itself.
- `Generation` - Claude Code, Codex or Ollama, through your own CLI session. No API key, ever.
