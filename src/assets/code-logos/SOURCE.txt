Language logos of the code-block badge, embedded in src/code-logos.ts.

- Seti, the file icons VS Code shows by default: glyphs of the seti.woff
  font of VS Code 1.139.1 (extensions/theme-seti/icons), drawn as SVG paths
  with their dark-theme colour; language mapping from
  vs-seti-icon-theme.json. MIT: LICENSE-seti.txt (Seti UI by Jesse Weed,
  and the theme-seti extension of VS Code).
- Devicon 2.17.0 (https://devicon.dev, npm "devicon"), MIT licence:
  LICENSE-devicon.txt. Files icons/<name>/<name>-original.svg, for the
  languages Seti has no glyph for and for MySQL, PostgreSQL and SQLite.

Optimized with svgo 4 (--multipass). The glyph frame and precision are
described in the header of src/code-logos.ts.

The logos themselves remain trademarks of their respective owners; they are
shown only to name the language of a code block.
